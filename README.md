# Tantoluwa Portfolio

## Overview
This project is a personal portfolio website for Oloyede Tantoluwa Emmanuel with a working contact form powered by Node.js, Express, and Nodemailer.

## Main files
- index.html: portfolio page structure and content
- styles.css: all visual styling and responsive behavior
- script.js: client-side interactions such as theme toggle, navbar behavior, and contact form submission
- server.js: backend server that serves the portfolio and handles the contact form API

## Notes
- The contact form email sending works through the server endpoint /api/contact.
- The older standalone mail files email.js and email2.js are not used by the current setup and can be removed if desired.
